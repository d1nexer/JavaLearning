# Java Learning Repository 

## О репозитории

Этот репозиторий создан для **изучения языка программирования Java** с нуля и до продвинутого уровня. Здесь собраны учебные материалы, примеры кода, практические задания.

Репозиторий ведётся в процессе обучения, поэтому материалы регулярно дополняются и обновляются.

## Цели обучения

- Освоить синтаксис и базовые конструкции языка Java
- Понять принципы объектно-ориентированного программирования (ООП)
- Изучить стандартную библиотеку Java (Java Standard Library)
- Научиться работать с коллекциями, исключениями, потоками ввода-вывода
- Освоить многопоточность и функциональное программирование (Stream API, лямбды)
- Познакомиться с системой сборки Maven/Gradle
